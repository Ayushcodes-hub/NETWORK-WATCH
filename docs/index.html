WINDOWS DESKTOP APPLICATION

Run NETWORK WATCH locally.

Download the standalone Windows executable. It starts a local monitoring server and opens the dashboard in your browser. Your local monitoring database is stored on your computer.

Download NETWORK-WATCH.exe All Releases

Install Npcap before using live packet capture. Administrator permissions may be required. Npcap is a separate dependency and is not bundled with the executable.

Windows may display a SmartScreen warning because the application is not digitally signed. Download only from this project's official GitHub Releases page.
